# RoomSeek

RoomSeek is a MERN stack web application that allows users to find rental rooms and enables room owners to add and manage room listings.

## Features

- **User Roles**: Room Finder & Room Owner
- **Search**: Find rooms by location, price, type, and preferences.
- **Listings**: Owners can add rooms with details and images.
- **Dashboard**: Manage your room listings.

## Tech Stack

- **Frontend**: React, Vite, Tailwind CSS
- **Backend**: Node.js, Express.js
- **Database**: MongoDB
- **Authentication**: JWT (JSON Web Tokens)
